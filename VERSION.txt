SimCity SNES Static Recomp
Version: 1.2.0
Platform: native 64-bit Windows
Executable: Launcher.exe
Frontend: native Win32/GDI launcher and video; SDL3 gamepad input
Audio: Full Static, 32,040 Hz stereo PCM through four native WinMM buffers
ROM: required externally and not included

Changes in 1.2.0:
- Compacted repeated generated-core bookkeeping into compile-time macros.
- Removed 2,503 unreachable exact contexts shadowed by earlier dispatch authority.
- Preserved exact PBR:PC:E:M:X dispatch and fail-closed static execution.
- Added reproducible compaction and context-pruning receipts and verification tools.
- Reduced the static-core source and native release binary sizes.
- Replaced the host frontend and core connector with the proven native Win32 structure.
- Replaced adaptive SDL audio streaming with four fixed WinMM PCM buffers, full pre-roll, and resume fade.
- Replaced SDL GPU presentation with direct Win32 GDI framebuffer presentation.
- Adopted the matching input latch, settings dialogs, and gamepad host adapter.
- Matched Bubble Bobble's complete launcher toolbar layout, including the Settings button.
- Unified first-run Welcome, F1 help, and About information windows with reliable Tab and Shift+Tab navigation.
- Standardized F1 through F8: Welcome, save/load snapshot, Settings, controller bindings, Audio, Run, and capture.
- Replaced free-form audio widgets with fixed 0-100 volume and supported-latency drop-downs; accepted settings now flush immediately.
- Moved snapshots into Saves and added release-safe Saves and Screenshots folders with Readme files.
- Removed the redundant Getting Started, shortcut-only, and first-run ROM notice windows.
- Removed the remaining Help menu, Ctrl+O/F9 extras, and WAV recorder so Bubble Bobble's File/Settings menu structure is retained; SimCity's slot-based snapshots are the deliberate frontend difference.
- Renamed the toolbar Keys button to Controls and removed the redundant Audio and Controls launchers from the Settings window.
- Changed Pause on Focus Loss to disabled by default for new installations.
- Reworked Settings into focused General and Display groups and added the meaningful quick-snapshot slot selector.
- Consolidated frontend, controls, audio, snapshot slot, remembered ROM path, and the explicit WelcomeShown first-run flag into one settings.ini with automatic legacy-INI migration; deleting the file restores defaults and shows Welcome again.
- Corrected Welcome so F2/F3 describe the snapshot windows while 1/2 describe quick save/load of the current slot.
- Made Escape reliably close Welcome, About, Settings, Controller Bindings, Audio Settings, and snapshot windows.
- Removed the unused ShowStatusText setting and restored the remembered external ROM path at startup.
