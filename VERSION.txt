SimCity SNES Static Recomp

- Reduced the static-core source and native release binary sizes.
- Replaced the host frontend and core connector with the proven native Win32 structure.
- Replaced adaptive SDL audio streaming with four fixed WinMM PCM buffers, full pre-roll, and resume fade.
- Replaced SDL GPU presentation with direct Win32 GDI framebuffer presentation.
- Adopted the matching input latch, settings dialogs, and gamepad host adapter.
