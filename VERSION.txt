SimCity SNES Static Recomp
Version: 1.4.1
Platform: native 64-bit Windows
Executable: Launcher.exe
Frontend: native Win32/GDI; SDL3 gamepad input
Audio: Full Static 32,040 Hz core PCM; DirectSound speaker output
ROM: required externally and not included

Changes in 1.4.1:
- Recovered the missing exact-ROM S-CPU contexts at 00:B033 through 00:B03C that can occur while developed scenario cities are active.
- Added a conservative closure guard for the remaining decodable S-CPU contexts and verified that the current authority has no additional missing decodable contexts.

Previous release changes in 1.4.0:
- Ported the current Jungle Strike native frontend structure, including its accessible dialogs, exact rational NTSC pacing, controller latch, quick snapshots, DirectSound output, audio diagnostics and settings persistence.
- Retained and adapted SimCity's real 398x239 Wide Screen feature, its default-on toolbar control, runtime switching and Display/Widescreen setting.
- Corrected windowed presentation to preserve the active 256- or 398-pixel framebuffer aspect instead of forcing 4:3 onto Wide Screen output.
- Preserved SimCity's fullscreen Wide Screen overscan crop while keeping native presentation letterboxed or pillarboxed as required.
- Made F8 save the active 256- or 398-pixel core framebuffer in windowed mode and the exact borderless client presentation in fullscreen mode.
- Replaced the old SDL3 speaker stream with the Mesen-derived DirectSound ring-buffer design used by the newer SNES recompilations.
- Added cubic-Hermite, linear and nearest speaker resamplers with selectable 32,040, 44,100, 48,000 and 96,000 Hz output rates.
- Added cursor-measured queue depth, pre-roll, bounded drift correction, integral correction, recovery, underrun realignment and detailed diagnostics.
- Kept optional added latency disabled by default; its enabled range is 0-40 ms.
- Replaced the former emulator S-DSP runtime with the project-owned fixed 32-phase S-DSP used by the newer static recompilations.
- Added explicit ARAM/register/PCM knownness, semantic unknown-read failure, DSP overflow accounting and deterministic PCM hashing.
- Kept SimCity's own ROM-derived exact-PC S-SMP authority, dispatcher, code bitmap, uploader and fail-closed diagnostics.
- Corrected SPC700 discarded reads before stores while preserving MMIO timing and side effects.
- Upgraded direct snapshots to preserve S-SMP ARAM-knownness and complete project-owned S-DSP state for deterministic PCM continuation.
- Added project-DSP microtiming, linked-purity and real-ROM snapshot-continuation release gates.
- Confirmed 10,000 neutral frames and all meaningful tutorial, widescreen, construction, scenario and Freeland routes with zero PCM overflow.
- Ordered the Welcome shortcuts as Escape, quick-slot keys 1/2, then the uninterrupted F1-F8 function-key group.
- Reserved Escape, quick-slot keys 1/2 and the complete F1-F8 launcher range in Controls so an intercepted shortcut cannot be saved as an unusable gameplay binding.
- Restored the main window's foreground, active-window and keyboard focus after Welcome, About, snapshot and audio dialogs close, matching the completed Top Gear frontend behavior.
- Verified that Welcome appears once for a clean configuration, persists General/WelcomeShown in settings.ini when closed, and remains available later through F1.
- Confirmed the final native fullscreen, 398x239 widescreen fullscreen and 256x239 windowed screenshots against SNES reference captures.
- Completed interactive audio validation with no crackling, stutter, delay or other reported sound issue.
- Updated executable metadata, About text, diagnostic logs and documentation to 1.4.0.
